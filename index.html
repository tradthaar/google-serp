Ne İşe Yarar ve Neden Kullanmalısınız?

Sıradan botların aksine arama motorlarının en çok değer verdiği doğal kullanıcı sinyallerini (CTR, Dwell Time, Organik Etkileşim) üreterek web sitenizi rakiplerinizin üzerine taşır.

Organik CTR (Tıklama Oranı) Yükseltme

Ne İşe Yarar: Hedef anahtar kelimelerinizde Google sonuçlarını tarar, sitenizi bulur ve organik olarak tıklar.

Neden Kullanmalısınız: Google algoritmasında CTR en kritik sıralama faktörüdür. Düzenli organik tıklama alan sayfalar Google gözünde popülerleşir ve sıralamada hızla yükselir.

Dwell Time (Sitede Kalma Süresi) Güçlendirme

Ne İşe Yarar: Tıklama sonrası sitenizde belirlenen süre boyunca (15-60 sn) kalarak doğal sayfa içi etkileşim üretir.

Neden Kullanmalısınız: Ziyaretçinin hemen çıkmadığını gören Google, içeriğinizin kullanıcıyı tatmin ettiğine karar verir; hemen çıkma oranını (Bounce Rate) düşürerek otoritenizi artırır.

Ceza ve Spam Radarına Girmeme (Anti-Spam)

Ne İşe Yarar: Mekanik hareketler yerine gerçek bir insanın imleç salınımlarını ve doğal donanım kimliğini simüle eder.

Neden Kullanmalısınız: Sıradan botlar Google tarafından tespit edilip sitenizin ceza almasına yol açar. Tradthar ile sitenizin güvenilirlik puanı (Trust Score) asla riske atılmaz.

Rakiplerin Önüne Geçme & Rekabet Üstünlüğü

Ne İşe Yarar: Rekabetin yoğun olduğu sektörlerde sitenize sürekli ve istikrarlı arama hacmi ve tıklama kazandırır.

Neden Kullanmalısınız: Sadece geleneksel SEO ile aylarca beklemek yerine, Google'a sitenizin o anahtar kelimede en çok ilgi gören sonuç olduğu algısını vererek sıralama kazanımını hızlandırırsınız.

Maksimum Bütçe ve Proxy Tasarrufu

Ne İşe Yarar: Akıllı veri engelleme kalkanı ile gereksiz resim ve medyaları yüklemeyerek veri kullanımını %90 azaltır.

Neden Kullanmalısınız: Pahalı residential proxy kotalarınızı boşa harcamadan, aynı bütçeyle 10 kata kadar daha fazla arama ve organik tıklama operasyonu gerçekleştirirsiniz.

Tam Otomasyon & Zahmetsiz Büyüme

Ne İşe Yarar: İster arka planda (headless) ister paralel çoklu oturumlarla tüm süreci insan müdahalesi olmadan yönetir.

Neden Kullanmalısınız: Manuel arama yapma ve tıklama çabalarını tamamen ortadan kaldırır; tek bir yapılandırma ile 7/24 organik büyüme motorunuz haline gelir.

Dokümantasyon & Kullanım

Hızlı Başlangıç Rehberi

Birkaç basit adımla botu yapılandırın ve hedeflenen organik SERP trafiğini başlatın.

⚙️ config.json Yapılandırma Kılavuzu

Uygulamanın çalışacağı dizinde bulunan config.json dosyasını metin editörü ile açarak arama ve hedef parametrelerinizi belirleyin:

config.json 
{
  // Google'da aranacak anahtar kelime
  "keyword": "antalya transfer",

  // Tıklanacak organik hedef domain (https:// veya www olmadan)
  "targetDomain": "shuttleforantalya.com",

  // Hedef bulunana kadar taranacak maksimum SERP sayfası
  "maxPages": 3,

  // Hedef sitede geçirilecek süre aralığı (saniye)
  "minDwellTimeSec": 15,
  "maxDwellTimeSec": 30,

  // false = ekranda tarayıcıyı izle, true = arka planda sessiz çalış
  "headless": false,

  // Eşzamanlı çalışacak paralel tarayıcı sayısı
  "concurrency": 2,

  // Toplamda icra edilecek toplam döngü sayısı
  "totalRuns": 5,

  // Görevler arası dinlenme süresi (saniye)
  "delayBetweenRunsSec": 3,

  // Hedef sitede medya, font ve CSS'i engelleyerek proxy kotasını korur
  "blockMediaAndStyles": true,

  // User-Agent rotasyon modu: "auto" (15+ tarayıcı rotasyonu), "mixed" (45+ tarayıcı), "windows", "mac", "linux"
  "userAgentMode": "auto",

  // Çözünürlük rotasyonu: true = Her oturumda en popüler çözünürlükler (1080p, 2K, Retina vb.) arasından seçer
  "randomizeViewport": true,

  // Otomatik giriş kimlik bilgileri (boş bırakılırsa konsolda sorar)
  "auth": {
    "username": "kullanici_adiniz",
    "password": "guclu_sifreniz"
  }
}

🪟 Windows Üzerinde Çalıştırma

  1. İndirdiğiniz googlebot.exe dosyasını bir klasöre alın.
  2. Aynı klasöre config.json dosyasını koyun.
  3. googlebot.exe dosyasına çift tıklayarak çalıştırın veya PowerShell üzerinden başlatın:
PowerShell 
.\googlebot.exe

Uygulama açılışta kimlik doğrulamasını tamamlayıp kullanıcıdan [ENTER] onayı bekler. Hazır olduğunuzda Enter'a basarak süreci başlatabilirsiniz.

🍎 macOS (MacBook) Üzerinde Çalıştırma

M1, M2, M3 veya M4 çipli MacBook'unuzda Terminal açıp ilgili dizine geçtikten sonra şu adımları izleyin:

Terminal (macOS) 
# 1. Çalıştırma izni verin:
chmod +x googlebot-darwin-arm64

# 2. İnternetten indirildiği için Gatekeeper kısıtlamasını kaldırın (Tek seferlik):
xattr -cr googlebot-darwin-arm64

# 3. Botu başlatın:
./googlebot-darwin-arm64

🐧 Linux Sunucuda (Headless / Xvfb) Çalıştırma

Ubuntu/Debian sunucularda Chromium bağımlılıklarını kurarak arka planda veya Xvfb ile çalıştırabilirsiniz:

Bash (Linux) 
# 1. Gerekli kütüphaneleri yükleyin:
sudo apt-get update && sudo apt-get install -y libnss3 libatk1.0-0 libatk-bridge2.0-0 libcups2 libdrm2 libxkbcommon0 libxcomposite1 libxdamage1 libxfixes3 libxrandr2 libgbm1 libasound2 xvfb

# 2. Çalıştırma izni verin:
chmod +x googlebot-linux-x64

# 3. config.json'da "headless": true ise doğrudan çalıştırın:
./googlebot-linux-x64

# 4. Arayüzlü (pencereli) modu sanal ekranda çalıştırmak için:
xvfb-run -a ./googlebot-linux-x64

🛡️ Doğal Cihaz Kimliği & Stealth Mimarisi

Birçok otomatik botun Google Botguard tarafından engellenmesinin temel sebebi "Parmak İzi Uyuşmazlığı" (Fingerprint Mismatch) hatasıdır. Örneğin bir Linux veya Mac üzerinde çalışırken User-Agent'ı yapay biçimde Windows göstermek, GPU ve font listesiyle çelişerek tespit edilmenize yol açar.

Tradthar Çözümü: Uygulama, üzerinde çalıştığı cihazın orijinal işletim sistemini, WebGL GPU çekirdeğini ve ekran çözünürlüğünü %100 doğal tutarak organik bir ev kullanıcısı gibi davranır.
